** Definição do Ambiente e Saída
*** set terminal <terminal_type> <options>

    : Define o tipo de saída gráfica (e.g., png, jpeg, svg, pdf, qt, x11).
    : <options> dependem do terminal (e.g., size, font, linewidth).

*** set output "<filename>"

    : Redireciona a saída gráfica para um arquivo. Sem filename, retorna para a saída padrão.

*** unset output

    : Cancela a redireção para arquivo.

*** set encoding <encoding>

    : Define a codificação de caracteres (e.g., iso_8859-1, utf8).

*** set locale "<locale>"

    : Define as configurações regionais para formatação de números e datas.

*** set font "<fontname>,<fontsize>"

    : Define a fonte padrão para textos.

*** set size <width>,<height>

    : Define as dimensões da saída gráfica (relativas ou absolutas).

*** set origin <x>,<y>

    : Define a origem do gráfico na saída (relativa).

*** set termoption <option>

    : Define opções específicas do terminal.

** Definição do Gráfico
*** plot <ranges> <data> <style>, <data> <style>, ...

    : Comando principal para plotar dados.
    : <ranges>: define os limites dos eixos (e.g., [xmin:xmax], [ymin:ymax]).
    : <data>: especifica a fonte dos dados (arquivo, inline, função).
    : <style>: define o estilo de plotagem (e.g., lines, points, linespoints, histogram).

*** splot <ranges> <data> <style>, <data> <style>, ...

    : Comando para plotar dados em 3D (superfícies, pontos, linhas).
    : <ranges>: define os limites dos eixos x, y e z.

*** replot

    : Re-executa o último comando `plot` ou `splot`.

** Definição de Eixos
*** set xrange [<min>:<max>]

    : Define os limites do eixo x.

*** set yrange [<min>:<max>]

    : Define os limites do eixo y.

*** set zrange [<min>:<max>]

    : Define os limites do eixo z (para `splot`).

*** set autoscale <axis>

    : Ativa ou desativa o ajuste automático da escala do eixo (<axis>: x, y, z, xy, etc.).

*** unset autoscale <axis>

    : Desativa o ajuste automático da escala do eixo.

*** set [xyz]tics <options>

    : Controla a colocação e formatação das marcas de escala nos eixos.
    : <options>: e.g., add, border, format, interval, rotate, scale.

*** unset [xyz]tics

    : Desativa as marcas de escala do eixo.

*** set [xyz]label "<text>"

    : Define o rótulo do eixo.

*** unset [xyz]label

    : Remove o rótulo do eixo.

*** set [xyz]minorgrid

    : Ativa as linhas de grade menores nos eixos.

*** unset [xyz]minorgrid

    : Desativa as linhas de grade menores nos eixos.

*** set [xyz]grid

    : Ativa as linhas de grade nos eixos.

*** unset [xyz]grid

    : Desativa as linhas de grade nos eixos.

*** set logscale <axis>

    : Define a escala logarítmica para o eixo.

*** unset logscale <axis>

    : Remove a escala logarítmica do eixo.

** Legenda e Título
*** set title "<text>"

    : Define o título do gráfico.

*** unset title

    : Remove o título do gráfico.

*** set key <options>

    : Controla a aparência e a posição da legenda.
    : <options>: e.g., bottom, top, left, right, inside, outside, box, nobox.

*** unset key

    : Remove a legenda.

** Estilos de Plotagem
*** with lines

    : Plota os dados conectados por linhas.

*** with points

    : Plota os dados como pontos.

*** with linespoints

    : Plota os dados com linhas conectando pontos.

*** with impulses

    : Plota barras verticais da linha de base até os pontos.

*** with steps

    : Plota uma função degrau.

*** with fsteps

    : Plota uma função degrau com o degrau no ponto.

*** with histeps

    : Plota uma função degrau com o degrau antes do ponto.

*** with boxes

    : Plota caixas (retângulos).

*** with histograms

    : Plota um histograma.

*** with dots

    : Plota pequenos pontos densamente espaçados.

*** with vectors

    : Plota vetores.

*** with filledcurves

    : Plota áreas preenchidas.

*** with pm3d

    : Plota dados 3D com cores mapeadas para um terceiro valor.

*** with image

    : Plota dados como uma imagem.

*** with labels

    : Plota texto em coordenadas específicas.

*** with boxplot

    : Plota um box plot (diagrama de caixa).

** Dados e Funções
*** using <specifiers>

    : Especifica quais colunas dos dados usar e como transformá-las.
    : <specifiers>: e.g., 1:2, 2:($3+$4), "stringcolumn":numericcolumn.

*** inline data

    $DATA
    1 2
    3 4
    5 6
    end
    : Define dados diretamente no script.

*** plot "<filename>" using ...

    : Plota dados de um arquivo.

*** f(x) = <expression>

    : Define uma função de uma variável.

*** g(x,y) = <expression>

    : Define uma função de duas variáveis.

*** set samples <n>

    : Define o número de pontos a serem amostrados para plotar funções.

*** set isosamples <n>

    : Define o número de amostras em cada direção para `splot` de funções.

** Personalização Adicional
*** set style <style_element> <options>

    : Define estilos para diferentes elementos do gráfico (e.g., line, point, fill).

*** set palette <options>

    : Controla a paleta de cores para plotagens com `pm3d` ou `image`.

*** set colorbox <options>

    : Controla a exibição da barra de cores associada à paleta.

*** set arrow <tag> <options>

    : Desenha uma seta no gráfico.

*** set object <tag> <options>

    : Desenha formas geométricas (e.g., rectangle, circle, ellipse) no gráfico.

*** set label <tag> "<text>" at <x>,<y>{,<z>} <options>

    : Coloca um rótulo de texto em coordenadas específicas.

** Controle de Fluxo e Scripts
*** load "<filename>"

    : Executa comandos de um arquivo de script do gnuplot.

*** if (<condition>) { ... } else { ... }

    : Estrutura condicional.

*** do for [var = start:end:increment] { ... }

    : Loop `for`.

*** pause <time> "<message>"

    : Pausa a execução do script.

*** print <expression>

    : Imprime o valor de uma expressão.

** Ajuda e Informação
*** help <command>

    : Exibe a ajuda para um comando específico.

*** show <parameter>

    : Exibe o valor atual de um parâmetro.

*** show all

    : Exibe todos os parâmetros configuráveis.

*** version

    : Exibe a versão do gnuplot.
